"What are the four main phases of the Symfony Container Lifecycle in their precise chronological order?"	"1. Compile (Optimization & Optimization Passes) -> 2. Freeze (Locking definitions) -> 3. Cache Generation (Writing PHP files to disk) -> 4. Instantiation (Runtime execution)"
"Why does Symfony completely remove or inline private services during the container optimization phase?"	"To drastically reduce memory usage and speed up service instantiation at runtime by eliminating tracking overhead inside the cached container."
"What are the five types of compiler passes in the order in which the container runs them, and which type does addCompilerPass() use by default?"	"beforeOptimization, optimization, beforeRemoving, removing, afterRemoving (the PassConfig::TYPE_* constants). They run after the MergeExtensionConfigurationPass. The default type is beforeOptimization with priority 0."
"Which pass type contains RemoveUnusedDefinitionsPass, and which pass at its end turns errors that were collected earlier (for example autowiring failures) into an exception?"	"The removing type (PassConfig::TYPE_REMOVE). Its last pass is DefinitionErrorExceptionPass, which throws the collected errors as a RuntimeException. AutowirePass itself runs earlier, in the optimization type."
