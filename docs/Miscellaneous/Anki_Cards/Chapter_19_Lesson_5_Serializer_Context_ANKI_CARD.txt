"Which namespace provides the #[Groups] attribute in Symfony 8, and what happened to the Annotation namespace?"	"Symfony\Component\Serializer\Attribute\Groups. The class aliases in the Annotation namespace were removed in 8.0."
"A class imports a #[Groups] attribute from a class that does not exist (for example the removed Annotation alias). Which error does PHP report?"	"None at declaration time. PHP only loads an attribute class when newInstance() is called on the reflection attribute. The serializer then does not see the attribute, so the groups silently have no effect."
"How does the group filter work in the Serializer?"	"If the context contains the option groups, only properties in at least one of these groups are normalized or denormalized. Without the option, all accessible properties are used."
